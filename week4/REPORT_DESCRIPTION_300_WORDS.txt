This Week 4 project develops and evaluates a supervised machine-learning model for binary classification using the Breast Cancer Wisconsin (Diagnostic) dataset distributed through scikit-learn. The objective is to predict whether a tumor observation is malignant or benign from 30 numerical measurements derived from digitized fine-needle aspirate images. Logistic Regression was selected as the baseline algorithm because it is appropriate for binary classification, computationally efficient, and relatively interpretable. The workflow separates predictors and target, uses a stratified 80/20 train-test split, and places StandardScaler and Logistic Regression inside a scikit-learn Pipeline. This prevents information from the test set from leaking into the preprocessing stage.

Model performance is evaluated using accuracy, precision, recall, F1-score, ROC-AUC, and a confusion matrix. On the held-out test set produced with random_state=42, the model achieved 98.2% accuracy, 98.6% precision, 98.6% recall, 98.6% F1-score, and a ROC-AUC of 0.995. The confusion matrix contained one false negative and one false positive. The report includes four visualizations: a confusion matrix, ROC curve, metric comparison chart, and standardized feature-coefficient chart. These visuals provide complementary views of performance and make the evaluation easier to understand than a single accuracy number.

The analysis also discusses important machine-learning risks. A single train-test split can give an optimistic or unstable estimate, so stratified k-fold cross-validation should be used for stronger validation. In a medical context, false negatives can be more costly than false positives, meaning the classification threshold should be selected according to the real-world cost of errors. The report therefore treats the result as an educational model evaluation rather than a clinical diagnostic claim. Future improvements could include hyperparameter tuning, feature selection, nonlinear models, probability calibration, threshold optimization, and independent external validation. Overall, the project demonstrates a complete and leakage-aware machine-learning development process.
