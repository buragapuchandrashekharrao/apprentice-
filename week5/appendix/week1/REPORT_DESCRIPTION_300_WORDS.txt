This Week 1 data preparation project demonstrates a complete, reproducible data-science workflow using the public Titanic passenger dataset. The project begins by acquiring the dataset from a public GitHub source and inspecting its structure, data types, summary statistics, missing values, and duplicate records. The cleaning stage preserves the raw data while creating a separate working dataset. Exact duplicates are removed, numeric fields are explicitly converted to numeric types, and categorical text is standardized. Missing Age values are imputed using the median age for passengers sharing the same passenger class and sex, while the small number of missing Embarked values are replaced with the most frequent port. Because the raw Cabin field is highly incomplete, the project extracts a deck-level feature and represents unavailable cabin information as “Unknown” rather than discarding potentially useful information. Extreme Fare observations are identified using the interquartile-range method and capped instead of removed, which limits the effect of unusually high fares while preserving genuine passenger records. Categorical variables are encoded and continuous variables are standardized for future machine-learning use.

The exploratory analysis includes visualizations of missing values, survival rates by sex and passenger class, and feature correlations. The analysis shows clear differences in survival across demographic and socioeconomic groups: female passengers survived at a much higher rate than male passengers, and passengers in higher classes generally had better survival outcomes. The project also highlights how missing-value patterns and extreme numerical values can affect downstream analysis if they are ignored. The final outputs include a cleaned CSV file, a cleaning summary, reusable Python code, and publication-ready figures. The repository is organized into raw data, processed data, source code, figures, and documentation folders so another student can reproduce the workflow easily. Overall, the project demonstrates why careful, justified data preparation is essential before statistical analysis or machine-learning modeling.
