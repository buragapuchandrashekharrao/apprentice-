# Week 4 — Machine Learning Model Development & Evaluation

## Objective
Build and evaluate a supervised machine-learning classification model.

## Dataset
Breast Cancer Wisconsin (Diagnostic) dataset, distributed through scikit-learn. It is a public dataset with 569 observations and 30 numeric features.

## Model
A Logistic Regression classifier is combined with StandardScaler in a Pipeline.

## Evaluation
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion matrix
- ROC curve
- Feature coefficient analysis

## Run
```bash
pip install -r requirements.txt
python src/main.py
```

The report is in `reports/`.
