# Week 2 — Advanced Data Visualization & Storytelling

This project turns the Week 1 Titanic dataset into a visual narrative for a non-technical audience.

## Run
```bash
pip install -r requirements.txt
python src/main.py
```

The script downloads the exact public Titanic CSV and generates five charts in `outputs/figures/`.

## Visualizations
1. Survival by sex and passenger class
2. Age distribution by survival outcome
3. Age × class survival heatmap
4. Fare × age scatter plot
5. Fare ECDF by survival outcome

The final submission report is in `reports/`.
